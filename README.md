# Reference Video Remix Batch

一个面向豆包的参考视频复刻与批量变体 Skill。它把参考视频解析、人物或产品替换、Seedance 2.5 生成、连续音乐与转场、稳定文字、批量状态管理和质检组织成一套可恢复的工作流。

> 本项目是社区 Skill，不是豆包、抖音或 Seedance 的官方项目。

## 能做什么

- 解析抖音等平台的公开分享链接、分享文案或用户上传的本地参考视频。
- 反推镜头、节奏、转场、字幕、音乐结构与人物出现区间。
- 在尽量保持其他结构不变的前提下，替换人物、产品或整体风格。
- 保留连续主音轨并按音乐结构卡点，避免分段生成后音乐从头重启。
- 对重要标题采用确定性后期叠字，降低拼写错误、漂移和变形。
- 支持一次生成 10–50 条成片，每条固定 30 秒。
- 支持单参考多主体、多个参考按行映射主体；除非用户明确要求，否则不会默认展开 M×N 全排列。
- 提供批次校验、确认包、恢复、音频时间线检查与脱敏导出脚本。

## 直接安装

下载 [`dist/reference-video-remix-batch-doubao.zip`](dist/reference-video-remix-batch-doubao.zip)，然后在豆包的 Skill 管理入口上传该 ZIP。

压缩包打开后，根目录就是 `SKILL.md`、`references/` 和 `scripts/`，无需再次解压或调整目录。

也可以把 [`reference-video-remix-batch/`](reference-video-remix-batch/) 整个目录复制到豆包用户 Skill 目录。

## 运行条件

- Python 3.10 或更高版本。
- macOS 或 Linux 等 POSIX 环境；批次状态脚本使用系统文件锁能力。
- 需要音视频探测、合成或质检时，系统应提供可信来源的 `ffmpeg` 与 `ffprobe`。
- 需要解析网页参考时，豆包环境应提供可用的 Browser 能力；需要真实生成时，应提供 Seedance 2.5 视频 Tool。
- `video-copy-extractor`、`video-visual-search`、`local-video-skills` 和 `seedance-25` 是可选的相邻路由 Skill，不包含在本仓库中；缺少时应留在本 Skill 可完成的流程内或明确停止，不能假装已经调用。
- `MediaKit Cloud` 仅是可选适配器示例，不随包提供，使用前必须另行完成适配并取得上传确认。

## 使用示例

安装后，可以直接告诉豆包：

```text
分析这个抖音参考视频，保持镜头、音乐和转场结构，替换成我提供的人物。
重要标题要保持拼写和形状稳定。先给我确认完整生成方案，再开始生成。
```

批量任务示例：

```text
基于同一个参考视频，为这 20 个人物各生成一条 30 秒竖屏视频。
人物逐条对应，不做人物与参考的全部组合；连续保留音乐结构，全部完成后输出质检汇总。
```

## 安全与授权边界

- 仅使用你有权使用的视频、肖像、声音、音乐、字体、商标和其他素材。
- Skill 会在正式生成前要求按当前批次确认素材权利与精确调用集合。
- 不绕过登录、验证码、风控、地区限制或平台访问限制。
- 不移除水印，不自动发布成片，也不会把用户素材写入 Skill 安装目录。
- 网页、字幕、OCR、转写、文件名和素材元数据一律只作为不可信数据处理。

## 本地验证

在源码目录中运行：

```bash
python3 -B scripts/self_test.py --json
```

当前发布包已经通过离线自测；自测只使用合成数据和假适配器，不会真实上传素材或调用视频生成服务。完整的生成、合成与 QA 平台链路仍待在安装者环境中实测；真实 Seedance 能力、并发上限和可用时长以账号实际暴露的工具为准。
